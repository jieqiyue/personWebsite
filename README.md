# 个人摄影博客

这是一个使用Vue.js和Vite构建的个人摄影博客网站，用于展示摄影作品和分享摄影技巧文章。

## 特点

- 响应式设计，适配各种设备
- Markdown支持，便于写作
- 图片画廊展示
- 文章标签分类
- 静态站点，无需后端

## 技术栈

- Vue.js 3
- Vue Router
- Markdown-it
- Vite

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```
